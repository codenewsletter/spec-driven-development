# How Engineers at Anthropic, Microsoft, and GitHub Run Spec-Driven Development

The Code's guide to spec-driven development. Three modules, thirteen lessons.

- `module-1-fundamentals.md`, `module-2-how-to-write-a-good-spec.md`, `module-3-how-to-run-sdd-end-to-end.md`: the content, which is the source of truth.
- `build_site.py`: turns the three markdown files into the static site in `site/`. Run `python3 build_site.py` after any content edit.
- `diagrams.py`: the one-hue SVG figures and the interactive checklist markup.
- `Sources/`: the source PDFs, links, and the spec shown in full in lesson 2.5.
- `writing-principles.md`, `rulepass.py`: the house rules and the mechanical rule pass.

Netlify publishes the `site/` folder.
